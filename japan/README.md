# ⛩️ Japan Bedtime Stories

100 cozy, funny, food-themed bedtime stories for ages 9–12, set in Japan. Each stars a sentient Japan food/treat character, weaves in light **Japanese** vocabulary, and ends with a warm Goodnight Blessing. Part of the *Boba Bedtime Stories* family.
