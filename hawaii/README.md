# 🌺 Hawaii Bedtime Stories

50 cozy, funny, food-themed bedtime stories for ages 9–12, set in Hawaii. Each stars a sentient Hawaii food/treat character, weaves in light **Hawaiian** vocabulary, and ends with a warm Goodnight Blessing. Part of the *Boba Bedtime Stories* family.

See also: [Character Guide](CHARACTER_GUIDE.md)
